📊 STATE MANAGEMENT (Pinia Store)

weddingStore.js
├── State:
│   ├── couple (bride/groom names)
│   ├── weddingDate
│   ├── venue (ceremony & reception)
│   └── rsvpList
└── Actions:
    ├── addRSVP(data)
    └── getRSVPCount()

Usage:
  import { useWeddingStore } from '@/stores/weddingStore'
  const store = useWeddingStore()

3. npm run build        -> Create optimized build

   ├── Apache/XAMPP     -> htdocs/vhosts/weddingpage/

💡 DEVELOPMENT WORKFLOW

1. Start dev server:       npm run dev

5. Open DevTools (F12) to debug
