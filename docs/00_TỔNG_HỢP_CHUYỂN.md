## 🚀 Cách Sử Dụng

**Để đọc tài liệu:**

```
Mở thư mục: docs/
Đọc: docs/START_HERE.md (hoặc QUICK_START.md)
```

**Để cấu hình:**

```
Mở: config.php
Chỉnh sửa: tên, ngày, địa điểm
```

**Để test:**

```
Truy cập: http://localhost/vhosts/weddingpage/index.php
Điều kiểm: form RSVP → gửi dữ liệu
Xem: http://localhost/vhosts/weddingpage/api/view-data.php
```
