🐛 NẾU CÓ LỖI

1. Login không hoạt động
   → Kiểm tra start.php
   → Kiểm tra session đã enable
   → Xóa cookies browser

2. Dữ liệu không hiển thị
   → Kiểm tra data.json, comments.json tồn tại
   → Kiểm tra JSON format đúng không
   → Kiểm tra quyền file (chmod 644)

3. Lỗi 401 Unauthorized
   → Cần đăng nhập trước
   → Kiểm tra session không hết hạn

4. Bảng trống
   → Kiểm tra file JSON có dữ liệu không
   → Test via start.php xem dữ liệu load được không
